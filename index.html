Simple, Self-Hosted Setup

SLIM runs on your own machine, giving you a private and secure chat environment. It's built with modern, open-source technology.

  1. Download the app and get the server running.
  2. Launch the client and create your account.
  3. Add your friends and start chatting!

Getting started is easy. Just run these commands:

# 1. Install dependencies $ pip install -r requirements.txt # 2. Start the server $ ./start_server.sh # 3. Launch the client $ ./start_client.sh
